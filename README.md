### 🧏‍♀️ Sign Learning Application

A responsive web-based e-learning application designed to support deaf children in learning sign language basics and improving communication skills.

This platform provides educational content, interactive practice tests, and access to speech and hearing specialists — all in one system.

---

### 🎯 Project Objective

The main objective of this system is to:

- Help deaf children learn language fundamentals at their own pace.
- Provide parents with a reliable platform for early language development.
- Enable access to speech and hearing consultants.
- Support self-learning through videos and practice tests.

---

### 👥 User Roles & Features

### 👤 User
- Learn or teach sign language (alphabets, actions, basics)
- Watch sign language education videos
- Take interactive practice tests
- Search nearby speech & hearing consultants and laboratories
- Book appointments
- View treatment history and medical progress

### 🩺 Doctor
- Update profile (specialization, availability, experience)
- View and manage appointment requests
- Access user medical history
- Respond to patient queries
- Cancel or approve appointments

### 🏥 Medical Service Provider
- Register and list services
- Respond to user messages
- Approve or decline service requests

### 🛠️ Admin
- Add and manage practice tests
- Upload video-based assessments
- Add motivational content
- Monitor users, doctors, and service providers
- Oversee overall system functionality

---

### 💡 Key Features

- Responsive web design (works across devices)
- Role-based authentication
- Online self-learning support
- Medical appointment booking
- User progress tracking
- Edutainment-based learning approach

### 📌 Conclusion

This project aims to empower deaf children by providing accessible and structured language learning resources through a web-based platform. By combining education, healthcare support, and interactive learning, the system contributes to improving communication skills and overall development.

The application is designed to be device-friendly, user-focused, and impactful in supporting early language acquisition and independent learning.
